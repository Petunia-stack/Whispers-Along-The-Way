# Whispers Along The Way

## Overview
Whispers Along The Way is an interactive Scripture-based experience built in Godot. The project explores how Scripture can appear naturally inside a digital world through character interaction and storytelling.

## Project Vision
Many digital experiences focus on entertainment and connection. This project creates a space where players can encounter messages of hope and reflection while exploring an interactive environment.

## Features
- 2D exploration environment
- Player movement system
- NPC interaction system
- Dialogue UI
- Scripture-based messages
- Interactive storytelling

## Technology
- Godot Engine
- GDScript
- GitHub for project sharing

## How To Run
1. Download or clone this repository.
2. Open the project in Godot 4.
3. Run the main scene.
